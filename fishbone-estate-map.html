Two-site compute

  • HQ Gen9 = the brain (256 GB + 2× P40).
  • HQ Gen10 = storage spine + primary PBS + PBX.
  • Beverley Gen10 = SSD replica + failover brain (2× P40).
  • Same Gen10 both sites → shared spares, one runbook.

Backup = 3-2-1(-1), all pull

  • Copy 1: HQ Gen10 (primary, append-only PBS).
  • Copy 2: Beverley (off-site, pulls).
  • Copy 3: R710 at HQ (local, pull + Wake-on-LAN, near-air-gapped).
  • −1: encrypted offline (cloud/USB).
  • Every copy pulls → no source can delete a backup (OI-26).

Links & resilience

  • Inter-site: airFiber AF-5 (583 m, VLANs 10/11 bridged) + spare radio.
  • IPsec VPN fallback over each site's own internet.
  • Tailscale for remote admin (split-tunnel).
  • HQ WAN: Wavenet FTTB (primary) + Starlink. BT Business backhaul ends 27 Oct (OI-24).

Status key

  • Live — in place now.
  • Upgrading Saturday — Gen9 RAM+P40; PBX still on Gen9 until the Gen10 is up.
  • Planned — Gen10 #1 (Fri order), Beverley Gen10, offline copy.
