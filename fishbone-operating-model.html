The two brains

  • Cloud workforce — office + coordination + drafting (broad knowledge, web, connectors).
  • Local brain — private, sovereign, photo/file-heavy work on estate data.
  • Office task → cloud; private/heavy → local. More shifts local over time.

The governance spine

  • AI proposes/drafts → human approves → executed → logged.
  • No AI sends email, pays, files or changes a live system on its own (§3).
  • The human is the gate on anything irreversible or outward.

Where things live

  • Google Drive — shared file surface (today) → mirrored to the NAS.
  • Smartsheet Hub — tasks + coordination between employees.
  • KBs (Drive + git) — each employee's memory + rules.
  • NAS — estate storage; feeds the local brain.

Direction of travel

  • From cloud-dependent → sovereign (A1 → D1).
  • The local brain takes on more; storage moves on-estate.
  • End state: run your own compute/storage/backups/phones — cloud by choice.
